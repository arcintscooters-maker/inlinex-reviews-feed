# inlinex-reviews-feed

Google Product Ratings feed for Merchant Center 10799544 (inlinexskate.com), built daily from Loox reviews.
`docs/product-reviews.xml` is served by GitHub Pages and fetched by Merchant Center every 24 h.
Build: `node build-feed.mjs` (needs SHOPIFY_CLIENT_ID / SHOPIFY_CLIENT_SECRET). No secrets live in this repo.
